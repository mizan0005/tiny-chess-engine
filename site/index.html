How it works

  1. Connect an EVM wallet.
  2. Register an available Agent ID on BNB Smart Chain.
  3. Verify the wallet binding using the public registry.
Profile creation requires an Agent ID NFT, a deployed contract, and a user-approved transaction with network gas. The profile label is not independently verified as the NFT's exact name.
